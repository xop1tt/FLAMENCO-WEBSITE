# Flamenco Studio — Liquid Glass Design System

This project uses Liquid Glass as a design system,
not merely as a glassmorphism visual effect.

Reference:
https://liquidglassdesign.com/

Primary design authority:
Apple Liquid Glass design principles.

The website should use:
- translucency
- optical depth
- lensing/refraction where technically appropriate
- adaptive highlights
- subtle specular reflections
- layered depth
- floating controls
- soft shadows
- rounded geometry
- fluid motion
- contextual lighting
- responsive material behavior

Do NOT reduce Liquid Glass to:
- generic backdrop-filter blur
- random transparent cards
- excessive glass panels
- glass-on-glass stacking
- neon gradients
- generic SaaS glassmorphism

Liquid Glass should primarily belong to:
- navigation
- controls
- floating UI
- contextual overlays

Content itself should remain visually clear and hierarchical.
